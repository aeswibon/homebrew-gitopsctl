# GitOpsCTL Homebrew Tap

This repository contains the official Homebrew tap for [GitOpsCTL](https://github.com/aeswibon/gitopsctl), a minimalistic, self-hosted, and externally managed GitOps controller for Kubernetes.

## Installation

To install GitOpsCTL using Homebrew on macOS or Linux, simply run:

```bash
brew install aeswibon/gitopsctl/gitopsctl
```

## Upgrading

To upgrade GitOpsCTL to the latest version:

```bash
brew upgrade gitopsctl
```
